One joke about Monday mornings, 200 characters at most, judged on laughs.

**Entry:** "Monday morning, my bed filed a restraining order against my alarm clock. The judge ruled in favor of the snooze button — case closed, back to sleep."

Run `node main.ts` — it writes the entry to `/output/entry.txt` and asserts the 1–200 character gate.
